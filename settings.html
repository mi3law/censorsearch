    Review and save

    Paste a fine-grained personal access token each time you save. It is used for this save only and never stored.

    How to make a token
    1. Open GitHub's new fine-grained token page, signed in as someone who can change the repository. The link fills in the name, owner and permissions below; check them.
    2. Token name: anything, such as "CensorSearch settings". Expiration: any; a short one is safer, since you can make a new token whenever you need one.
    3. Resource owner: the repository's owner.
    4. Repository access: Only select repositories, then choose this repository. GitHub can't fill this in.
    5. Permissions, Repository permissions: Contents: Read and write, and Pages: Read-only, so this page can find the branch GitHub Pages publishes.
    6. Click Generate token and copy it. GitHub shows it only once: keep it in a password manager, not in a file or a message.
    7. To stop a token working, revoke it at github.com/settings/personal-access-tokens. If the owner is an organization, it may need to approve the token first.

    This page changes only config.js, the file that tells the search page which sheet to read. The token you paste goes only to GitHub (api.github.com), for the save you ask for, and is not stored.
